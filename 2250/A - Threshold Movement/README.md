Then every element moves exactly once, simultaneously:</p><ul> <li> If $$$w_i \lt k$$$, the element at position $$$i$$$ moves to position $$$i-1$$$; </li><li> If $$$w_i \gt k$$$, the element at position $$$i$$$ moves to position $$$i+1$$$; </li><li> If $$$w_i=k$$$, the entire movement process fails immediately. </li></ul><p>An integer $$$k$$$ is <span class="tex-font-style-it">perfect</span> if the movement does not fail and, upon completion, every position from $$$1$$$ to $$$n$$$ contains exactly one element.</p><p>Determine whether a <span class="tex-font-style-it">perfect</span> integer $$$k$$$ exists.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases.
