## Problem Statement

<div class="header"><div class="title">C. Rank Subsequence</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p> </p><p>You are given $$$n$$$ elements arranged in a line, numbered $$$1, 2, \ldots, n$$$ from left to right.</p><p>You may delete any number of elements (possibly none). The remaining elements form a <span class="tex-font-style-bf">subsequence</span> and keep their relative order. Let the length of this subsequence be $$$m$$$. If the element with original index $$$i$$$ becomes the $$$j$$$-th element of the subsequence ($$$1 \le j \le m$$$), define</p><ul> <li> its <span class="tex-font-style-it">left rank</span> as $$$j$$$, and </li><li> its <span class="tex-font-style-it">right rank</span> as $$$m - j + 1$$$. </li></ul><p>For each element, you are given two integer segments $$$[l_i, r_i]$$$ and $$$[u_i, v_i]$$$. The $$$i$$$-th element is <span class="tex-font-style-it">valid</span> in a subsequence of length $$$m$$$ if and only if, when it occupies position $$$j$$$ in that subsequence, both of the following hold:</p><ul> <li> Its <span class="tex-font-style-it">left rank</span> is not in the range $$$[l_i, r_i]$$$ (i.e., $$$j \notin [l_i, r_i]$$$); </li><li> Its <span class="tex-font-style-it">right rank</span> is not in the range $$$[u_i, v_i]$$$ (i.e., $$$m - j + 1 \notin [u_i, v_i]$$$). </li></ul><p>A subsequence is <span class="tex-font-style-it">valid</span> if every element remaining in it is <span class="tex-font-style-it">valid</span>.</p><p>Find the maximum possible length of a <span class="tex-font-style-it">valid</span> subsequence. The answer may be $$$0$$$.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The first line contains the number of test cases $$$t$$$ ($$$1 \le t \le 5000$$$). the sum of $$$n$$$ over all test cases does not exceed $$$5000$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, print one integer — the
